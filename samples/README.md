# Grizzly

Простая читалка для **Markdown** и `текста`.

## Возможности

- Быстрый и нативный
- Темы и шрифты
- [x] Закладки строк

1. Откройте файл
2. Читайте

> Цитата для проверки.

```
brew install grizzly
```

| Формат | Расширение |
|--------|-----------|
| Markdown | .md |
| Text | .txt |

Блоки кода с указанием языка подсвечиваются:

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"  # comment
```

```swift
let numbers = [1, 2, 3].map { $0 * 2 }
```
