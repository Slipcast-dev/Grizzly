# Установка

Grizzly распространяется тремя файлами (версия 1.0.0) на [странице релизов](https://github.com/Slipcast-dev/Grizzly/releases).

| Платформа | Файл | Требования |
|---|---|---|
| macOS, Apple Silicon (M1 и новее) | `Grizzly-1.0.0-arm64.dmg` | macOS 13 Ventura или новее |
| macOS, Intel | `Grizzly-1.0.0-x64.dmg` | macOS 13 Ventura или новее |
| Windows x64 | `Grizzly-1.0.0-portable.exe` | Windows 10 или 11, 64-бит |

Не знаете, какой у вас Mac? Меню Apple → «Об этом Mac»: «Чип: Apple M…» — Apple Silicon, «Процессор: Intel…» — Intel.

## 1. Проверьте загрузку

В описании релиза указана контрольная сумма SHA-256 каждого файла. Сравните её со своей.

```bash
# macOS
shasum -a 256 ~/Downloads/Grizzly-1.0.0-arm64.dmg
```

```powershell
# Windows (PowerShell)
Get-FileHash $HOME\Downloads\Grizzly-1.0.0-portable.exe -Algorithm SHA256
```

Если значения отличаются — удалите файл и скачайте заново. Не запускайте его.

## 2. macOS

1. Откройте `.dmg` и перетащите **Grizzly** в **Программы**.
2. Приложение подписано ad-hoc, но **не нотаризовано Apple**, поэтому при первом запуске Gatekeeper его заблокирует.
   Сделайте одно из двух:
   - правый клик по **Grizzly** в «Программах» → **Открыть** → **Открыть**; или
   - Системные настройки → Конфиденциальность и безопасность → «Grizzly» заблокирован → **Всё равно открыть**; или
   - в Терминале снимите флаг карантина:

     ```bash
     xattr -dr com.apple.quarantine /Applications/Grizzly.app
     ```
3. Дальше приложение запускается как обычно.

Сделать Grizzly программой по умолчанию для типа файлов: Finder → выберите файл → «Свойства» (`⌘I`) → «Открывать в программе» → Grizzly → «Изменить все…».

Или прямо в Grizzly: *Настройки → Типы файлов* — нажмите на расширение (или «Сделать Grizzly приложением по умолчанию для всех»). Там же можно добавить свои расширения.

### Быстрый просмотр (пробел в Finder)

Вместе с Grizzly устанавливается расширение Quick Look: файлы Markdown, YAML, CSV/TSV и логи можно смотреть в Finder по пробелу, не открывая приложение. Положите `Grizzly.app` в `/Applications`, один раз запустите его, затем включите «Grizzly Quick Look» в *Системные настройки → Основные → Объекты входа и расширения → Просмотр (Quick Look)* (на старых macOS: *Конфиденциальность и безопасность → Расширения*). Если превью не появилось, выполните `qlmanage -r`.

Если что-то не работает:
- *Grizzly* в списке Quick Look дважды: macOS нашла несколько копий приложения. Оставьте только `/Applications/Grizzly.app` (удалите остальные, например из «Загрузок» или смонтированного образа), затем выполните `qlmanage -r`.
- Превью не появляется или не загружается: убедитесь, что установлена версия 0.3.2 или новее и расширение включено, затем выполните `qlmanage -r` и снова нажмите пробел.

## 3. Windows

1. Положите `Grizzly-1.0.0-portable.exe` куда угодно (папка, флешка). Установщика нет.
2. Запустите двойным кликом. SmartScreen может показать «Windows защитила ваш компьютер», потому что файл не подписан:
   **Подробнее → Выполнить в любом случае**.
3. Настройки и библиотека хранятся в папке `GrizzlyData` **рядом с .exe**
   (или в `%APPDATA%\Grizzly`, если папка недоступна для записи). Перенесите папку вместе с .exe — данные поедут с вами.

Командная строка: `Grizzly-1.0.0-portable.exe notes.md data.csv` откроет файлы. Повторный запуск передаёт файлы
уже работающему окну.

## Обновление и удаление

Grizzly не обновляется сам и никогда не обращается к сети. Чтобы обновиться, скачайте новый релиз.

- **macOS:** перетащите Grizzly в Корзину. Данные (по желанию): `~/Library/Application Support/Grizzly`
  (библиотека) и настройки `app.grizzly.Grizzly`.
- **Windows:** удалите .exe и папку `GrizzlyData` рядом с ним.

## Если что-то не так

| Симптом | Решение |
|---|---|
| macOS пишет, что приложение повреждено | Выполните команду `xattr` выше; не помогло — скачайте заново и сверьте сумму |
| macOS: не удаётся проверить разработчика | «Всё равно открыть» в разделе «Конфиденциальность и безопасность» |
| Windows показывает SmartScreen | «Подробнее → Выполнить в любом случае» |
| Антивирус блокирует .exe | Portable-сборка — самораспаковывающийся архив; если сумма совпала, добавьте исключение |
| Вместо текста кракозябры | Возможно, необычная кодировка; Grizzly пробует UTF-8, UTF-16, Windows-1251, ISO-8859-1 |
