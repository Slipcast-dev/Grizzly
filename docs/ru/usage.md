# Руководство пользователя

## Открытие файлов

- `⌘O` / `Ctrl+O` или перетащите файлы в окно либо на значок в Dock / панели задач.
- **Из Finder (macOS)**: двойной щелчок по файлу или «Открыть в программе → Grizzly». Если Grizzly не запущен, он стартует сразу с файлом; если запущен, файл открывается вкладкой в существующем окне (не во втором окне и не во второй копии приложения). Чтобы сделать Grizzly приложением по умолчанию, см. *Настройки → Типы файлов*.
- Несколько файлов открываются во вкладках. `⇧⌘]` / `⇧⌘[` (`Ctrl+Shift+]` / `[`) переключают вкладки.
- Расширения: `md markdown mdown txt text log json yaml yml csv tsv xml html htm ini conf toml tex rtf`,
  а также исходный код: `py pyw swift c h cpp cc cxx hpp hh hxx cs js mjs cjs jsx ts tsx css scss php`.
  Неизвестные открываются как обычный текст.

## Новый файл

`⌘N` / `Ctrl+N` (или кнопка *Новый файл* в боковой панели рядом с *Новой папкой*) открывает диалог: имя, папка и формат. Файл создаётся с небольшим
шаблоном (заголовок для Markdown, `{}` для JSON, строка заголовков для CSV, заготовка для HTML, C/C++, C#, PHP и т. д.) и открывается в новой вкладке в режиме
правки. Существующий файл заменяется только после подтверждения в системном диалоге.

## Три режима

| Режим | Клавиши (macOS / Windows) | Зачем |
|---|---|---|
| **Чтение** | `⌥⌘1` / `Ctrl+Alt+1` | Отрисованный Markdown, таблицы CSV |
| **Исходник** | `⌥⌘2` / `Ctrl+Alt+2` | Сырой текст с номерами строк, закладками и подсветкой |
| **Правка** | `⌥⌘3` / `Ctrl+Alt+3` | Изменить текст и сохранить `⌘S` / `Ctrl+S` |

Сохранение пишет текст в той кодировке, в которой файл был прочитан; UTF-8 BOM сохраняется.

## Markdown

Заголовки, выделение, код в строке, блоки кода, списки (нумерованные и маркированные), чек-листы (`- [x]`),
цитаты, таблицы и ссылки отображаются в текущей теме. Пример — [`samples/README.md`](../../samples/README.md).

## Другие форматы

| Тип | Как показывается |
|---|---|
| CSV / TSV | Таблица; разделитель (`,` `;` табуляция) определяется автоматически |
| Python, Swift, C / C++, C#, JavaScript, TypeScript, CSS, PHP | Подсветка в режимах чтения и исходника (и «на лету» в режиме правки на macOS); многострочные комментарии и строки поддерживаются. Блоки кода Markdown (```` ```python ````) подсвечиваются так же |
| JSON, YAML, INI / conf / TOML | Подсветка в режиме исходника |
| XML / HTML | Исходный текст с подсветкой (HTML не выполняется) |
| TeX | Подсветка |
| Log | Ошибки, предупреждения и успехи выделены цветом |
| RTF | Преобразуется в обычный текст |

## Закладки

В режиме исходника кликните по номеру строки — появится оранжевая закладка. Закладки запоминаются для каждого файла.
Колонку с номерами можно отключить в настройках.

## Поиск

`⌘F` / `Ctrl+F` открывает строку поиска; совпадения подсвечиваются по мере ввода. `⌘G` / `Ctrl+G` — следующее,
`⇧⌘G` / `Ctrl+Shift+G` — предыдущее (в Windows также `F3` / `Shift+F3`). `Esc` закрывает строку.

Поиск работает и в режиме «Правка»: совпадения подсвечиваются в редактируемом тексте.

## Выделить всё и копировать

В режимах «Чтение» и «Исходник» `⌘A` / `Ctrl+A` выделяет весь документ, `⌘C` / `Ctrl+C` копирует его целиком.

## Поиск файлов и теги

Поле **Поиск файлов** в сайдбаре ищет по началу названия файла или папки или любого слова в нём («гриз» найдёт «Мои заметки Гризли.md»). Запрос `#работа` ищет по тегам.

**Теги** находятся внизу сайдбара. Создайте тег кнопкой **+**, назначьте его через контекстное меню файла (*Теги*), переименуйте или удалите через контекстное меню тега. Теги — это `#слова`, которые вы пишете в файле Markdown / текст: они подсвечиваются в тексте, клик по ним показывает файлы с этим тегом, а при вводе `#` в режиме «Правка» появляется список известных тегов. В сайдбаре клик по тегу включает фильтр, клик по другим тегам сужает список (нужны файлы со всеми тегами), «Все теги» сбрасывает фильтр. «Переименовать» и «Удалить» в контекстном меню тега меняют текст во всех файлах с ним (файлы RTF и файлы с несохранёнными правками пропускаются).

## Орфография и грамматика

В режиме «Правка» файлы Markdown, TXT, RTF и TeX проверяются на русском и английском; ошибки подчёркиваются, исправления — в контекстном меню (на macOS проверяется и грамматика). Отключается в *Настройки → Текст*. Исходный код не проверяется. В Windows словари при первом использовании скачивает система.

## Эмодзи

Кнопка 😀 в правом краю панели инструментов (режим «Правка») открывает системную панель эмодзи (`⌃⌘Пробел` на macOS, `Win+.` в Windows). Если файл в 8-битной кодировке (Windows-1251, ISO-8859-1), где эмодзи не помещаются, Grizzly предложит сохранить его в UTF-8.

## Несохранённые изменения

При закрытии вкладки или окна с несохранёнными изменениями приложение спросит: сохранить, не сохранять или отмена.

## Обновления

*Настройки → Обновления → Проверить обновления* ищет новый релиз на GitHub. Если он есть, Grizzly скачает и установит его (сверив SHA-256 из описания релиза) и перезапустится. Проверка также тихо идёт при каждом запуске. На macOS приложение должно лежать в папке с правом записи (обычно «Программы»).

## Два файла рядом

`⌘\` / `Ctrl+\` делит окно на две панели — удобно сравнивать документы. Повторное нажатие возвращает одну панель.

## Сохранить как

Кнопка **Сохранить как…** в ряду кнопок боковой панели (`⇧⌘S` / `Ctrl+Shift+S`) сохраняет **копию** текущего файла, вместе с несохранёнными правками, в выбранное место.
Поле имени содержит имя файла **без расширения**. Формат выбирается в диалоге (Markdown, Text, JSON, YAML, CSV, TSV, Log, XML, HTML, INI/TOML, TeX, RTF) и добавляется при сохранении. Расширение, набранное вручную, имеет приоритет.
Текст между форматами не конвертируется, меняется только тип файла. Кодировка исходника сохраняется; если в ней нет каких-то символов, копия пишется в UTF-8, а RTF-источники сохраняются как текст в UTF-8.
Открытый документ не меняется. «Сохранить» (`⌘S`) по-прежнему записывает правки в исходный файл.

## Библиотека

В боковой панели — **виртуальная библиотека**: ваши папки и избранное (⭐), а во вкладке с часами — история открытых файлов. Это только список ссылок: файлы
она не перемещает, не копирует и не меняет.

- **Новая папка** (кнопка в заголовке «Файлы»): введите имя и нажмите Return (потеря фокуса поля тоже сохраняет). Перетащите файлы на папку, чтобы переместить их; правый клик по папке — переименовать или удалить.
- **История** (вкладка с часами): каждый открытый файл записывается туда, новые сверху. Удаление файла из библиотеки **не** убирает его из истории; открытие из истории показывает файл во вкладке, не возвращая его в боковую панель. Правый клик по записи — убрать её, «Очистить» — очистить список.
- В боковой панели один ряд одинаковых кнопок: **Новый файл**, **Открыть файл**, **Новая папка** (виртуальная) и **Сохранить как…**. Пункт *Файл → Добавить папку с диска…* (`⇧⌘O` / `Ctrl+Shift+O`) добавляет целую папку с диска (вложенные папки становятся папками
  в боковой панели; новые файлы подхватывает пункт «Обновить из папки»). Перетаскивание папки в окно делает то же самое.
- **Быстрый просмотр**: выберите файл в боковой панели и нажмите пробел (или пункт контекстного меню), чтобы посмотреть
  его без открытия вкладки.

## Просмотр в Finder и программа по умолчанию (macOS)

- **Просмотр в Finder**: когда включено расширение *Grizzly Quick Look* (см. инструкцию по установке), пробел на файле Markdown, YAML, CSV/TSV или лога показывает его оформленным, не открывая Grizzly.
- **Программа по умолчанию**: *Настройки → Типы файлов* — список поддерживаемых расширений. Нажмите на расширение, чтобы такие файлы открывались в Grizzly, используйте «Сделать Grizzly приложением по умолчанию для всех» или впишите своё расширение (например, `py`). Галочка означает, что Grizzly уже выбран; macOS может запросить подтверждение.

Где хранится:

| Платформа | Место |
|---|---|
| macOS | `~/Library/Application Support/Grizzly/library.json` |
| Windows | `GrizzlyData\library.json` рядом с .exe (или `%APPDATA%\Grizzly`) |

## Автообновление файла

Когда файл меняется на диске (скрипт сборки, синхронизация, ИИ-ассистент), появляется плашка. Нажмите на неё или
`⌘R` / `Ctrl+R`. Если включено автообновление в настройках, файл обновится сам; текст, который вы правите,
без вашего согласия не перезаписывается.

## Внешний вид

Настройки (`⌘,` / `Ctrl+,`):

- **Оформление:** как в системе, светлое или тёмное.
- **Разделы:** Оформление, Текст, Подсветка синтаксиса, Файлы, Язык и (macOS) Типы файлов — список слева; размер окна можно менять по ширине и высоте.
- **Подсветка синтаксиса:** общий переключатель и отдельный для каждого языка (Настройки → Подсветка синтаксиса).
- **Тема:** Xcode, GitHub, Solarized, Dracula, Monokai, Nord, One Dark. У тем без светлого варианта остаётся тёмный.
- **Шрифт** и **размер** (`⌘+` / `⌘-` при чтении), интервал заголовков (компактный / обычный / свободный).
- **Язык:** *Настройки → Язык* переключает между «Как в системе», Русский и English. При первом запуске интерфейс следует языку системы (русский на русской системе, иначе английский). На macOS после смены приложение предложит перезапуститься, в Windows язык меняется сразу.
