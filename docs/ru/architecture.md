# Архитектура

Grizzly — две реализации одного замысла: нативное приложение для macOS и порт на Electron для Windows. Общие у
них таблицы переводов и правила типов файлов, но не код.

```
Sources/Grizzly/          приложение macOS (SwiftUI, ~2,8 тыс. строк)
  App/        AppState, Settings, Theme, точка входа и команды меню
  Core/       Модель документа, загрузка и кодировки, парсер Markdown, CSV, подсветка (`SyntaxEngine` разбирает комментарии и строки между строками файла, `Syntax` красит по теме), поиск
  Features/   Вкладки, панели, исходник, редактор, поиск, боковая панель, настройки
  Render/     Отрисовка Markdown и таблиц CSV
  Library/    Виртуальная библиотека (папки / избранное) и история открытых файлов в JSON
QuickLook/    Расширение Quick Look (.appex): HTML-превью Markdown, CSV, YAML и логов;
              использует Core/FileLoader, FileType, CSVTable и MarkdownParser
resources/    Иконка и Localizable.strings (ru, en)
electron/     Порт для Windows
  main.js       Главный процесс: окно, меню, файловый ввод-вывод, передача файлов второму запуску, каталог данных
  preload.js    Узкий мост для рендерера (contextIsolation)
  renderer/     Интерфейс на чистом JS/CSS: state, core (парсеры), ui
scripts/      build-app.sh, make-dmg.sh, test.sh
tests/        Swift-тест (swiftc) и JS-тесты (node --test); VERSION — единый источник версии
samples/      По файлу каждого поддерживаемого типа для ручной проверки
```

## Поток данных

1. Приходит URL файла (диалог, перетаскивание, командная строка).
2. `FileLoader` декодирует его — UTF-8, UTF-8 BOM, UTF-16 BOM, затем Windows-1251 и ISO-8859-1 — и запоминает
   кодировку, чтобы сохранение было обратимым.
3. `FileType` по расширению определяет тип; `Document` строит представление (блоки Markdown, таблица CSV или
   строки с подсветкой).
4. Панели отображают документ в выбранном режиме; `Search` находит совпадения, панели их подсвечивают.
5. Наблюдатель за файлом замечает изменения на диске; панель показывает плашку и никогда молча не затирает несохранённую правку.

## Модель безопасности

- В обоих приложениях нет сетевого кода. Нет телеметрии и автообновления.
- HTML-файлы показываются как исходный текст, не отрисовываются и не выполняются.
- Рендерер Electron: `sandbox: true`, `contextIsolation: true`, `nodeIntegration: false` и
  Content-Security-Policy `default-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:`.
  Доступ к файлам — в главном процессе через мост preload.
- Библиотека хранит только ссылки (пути) и не меняет файлы, на которые они указывают.
- Релизные сборки не подписаны (или подписаны ad-hoc); целостность подтверждается опубликованными суммами SHA-256.

## Локализация

`resources/{ru,en}.lproj/Localizable.strings` содержат строки интерфейса. Русские ключи служат исходным текстом;
порт Electron получает `strings-en.json` из английского файла командой `npm run strings`.
