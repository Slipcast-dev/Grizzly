# Fonts shipped with Grizzly

Every family is licensed under the SIL Open Font License 1.1 (the license text sits in each family's folder as `OFL.txt`).
The files come from the [Google Fonts](https://github.com/google/fonts) repository and are copied unchanged into
`Grizzly.app/Contents/Resources/Fonts` by `scripts/build-app.sh`. Grizzly registers them for its own process only.

PT Sans, PT Serif, Inter, Roboto, Open Sans, Lato, Montserrat, Source Sans 3, Fira Sans, IBM Plex Sans, IBM Plex Serif,
Lora, Playfair Display, JetBrains Mono, Fira Code, Source Code Pro. All of them cover Latin and Cyrillic.
