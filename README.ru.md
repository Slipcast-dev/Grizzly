**Grizzly** — небольшая читалка и редактор для файлов Markdown, обычного текста и исходного кода (с подсветкой синтаксиса Python, Swift,
C/C++, C#, JavaScript, TypeScript, CSS и PHP). Открывает документ, показывает его так,
как удобно читать, позволяет форматировать текст, не показывая ни строчки разметки, и не мешает. Версия для macOS нативная (SwiftUI);
версия для Windows — переносимый порт на Electron (что есть только в macOS — в [журнале изменений](CHANGELOG.md)).

## Возможности

- **Режимы «Пользователь» и «Разработчик»** (macOS) — «Пользователь» правит текст без кода форматирования: он выглядит так, как читается (заголовки, жирный шрифт, списки с настоящими маркерами, галочки задач по клику, цитаты, разделители, таблицы с рамками, сворачиваемые разделы). «Разработчик» показывает файл таким, какой он есть: вся разметка, номера строк, **закладки** по клику на номер (сохраняются между запусками), подсветка **Python, Swift, C/C++, C#, JavaScript, TypeScript, CSS и PHP** (в том числе в блоках кода Markdown), а также JSON, YAML, INI/TOML, XML/HTML, TeX и логов. В режиме двух файлов у каждой панели свой режим, а границу между панелями можно двигать. (Windows: Чтение / Исходник / Правка.)
- **Форматирование** (macOS, Markdown) — панель, меню «Формат» и меню правой кнопки: Название / Заголовок / Подзаголовок / Основной текст / Моноширинный, жирный, курсив, подчёркнутый, зачёркнутый, пять мягких цветов маркера, выравнивание, маркированные / штриховые / нумерованные списки, списки задач, цитаты, разделители и таблицы. Файл остаётся обычным Markdown.
- **Вложения** (macOS) — фото, видео, PDF, любые файлы и ссылки на сайты: скрепкой, перетаскиванием или вставкой картинки из буфера. Файлы копируются рядом с документом в `<имя>.assets`.
- **Новый файл** — `⌘N` / `Ctrl+N`: выберите имя, папку и формат; файл создаётся с небольшим шаблоном и открывается для правки.
- **Сохранение не меняет файл** — исходная кодировка (UTF-8 с BOM и без, UTF-16,
  Windows-1251, ISO-8859-1) сохраняется (если в файл не помещаются эмодзи, предложим UTF-8). «Отменить» откатывает по одному слову; орфография и грамматика проверяются на русском и английском (Markdown, TXT, RTF, TeX).
- **Таблицы CSV / TSV** с автоопределением разделителя.
- **Сохранить как…** — копия файла в любом поддерживаемом формате и в выбранном месте, оригинал не меняется.
- **Поиск** с подсветкой по мере ввода, переход к следующему / предыдущему.
- **Поиск файлов** по началу названия или любого слова в нём (файлы и папки).
- **Теги как в Apple Notes** — `#хештеги` (можно с эмодзи), написанные в файле, и есть его теги: подсвечиваются в тексте, подсказываются при вводе, собраны в боковой панели; клик по одному или нескольким показывает файлы с ними; тег можно переименовать или удалить везде.
- **Уведомления** о сохранении, копировании, тегах и других действиях; кнопка панели эмодзи.
- **Обновления** — *Настройки → Обновления* проверяет GitHub (и при каждом запуске) и ставит новую версию прямо из приложения.
- **Вкладки** и **два файла рядом**.
- **Виртуальная библиотека** — папки (в том числе внутри папок; можно открыть папку целиком и выбрать несколько строк сразу) и избранное; ваши файлы она не трогает (текст файлов меняют только переименование и удаление тега — после подтверждения). История открытых файлов остаётся, даже если убрать файл из боковой панели.
- **Автообновление** — когда файл меняется на диске, появляется плашка (удобно для файлов, которые пишут скрипты и ИИ-инструменты).
- **7 тем** (Xcode, GitHub, Solarized, Dracula, Monokai, Nord, One Dark), светлая / тёмная / как в системе, эффект стекла macOS с настройкой прозрачности, 16 встроенных шрифтов (с кириллицей), свой шрифт и размер для интерфейса.
- **Быстрый просмотр в Finder** (macOS) — пробел на файле Markdown, YAML, CSV или лога показывает его без открытия Grizzly.
- **Выбор программы по умолчанию** (macOS) — Настройки → Типы файлов назначают Grizzly для нужных расширений.
- Интерфейс на **русском и английском**.

Поддерживаемые расширения: `md markdown mdown txt text log json yaml yml csv tsv xml html htm ini conf toml tex rtf` и исходный код: `py pyw swift c h cpp cc cxx hpp hh hxx cs js mjs cjs jsx ts tsx css scss php`.

## Быстрый старт

1. Скачайте файл для своей платформы со [страницы релиза](https://github.com/Slipcast-dev/Grizzly/releases/latest).
2. Следуйте инструкции [Установка](docs/ru/installation.md).
3. Откройте файл (`⌘O` / `Ctrl+O`) или перетащите его в окно. Для пробы есть файлы в [`samples/`](samples).

## Приватность и безопасность

В Grizzly нет телеметрии и аккаунтов. Единственное обращение к сети — проверка обновлений через публичный API GitHub Releases (при запуске и в *Настройки → Обновления*); обновление устанавливается только с GitHub по HTTPS и сверяется с SHA-256 из описания релиза (релиз без суммы не устанавливается). Интерфейс Windows-версии
выполняется в изолированном (sandbox) процессе с context isolation и строгим Content-Security-Policy. О
уязвимостях сообщайте приватно — см. [SECURITY.md](SECURITY.md).
